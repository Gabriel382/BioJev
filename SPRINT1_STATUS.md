# BioJev Sprint 1 status

## Implemented

- Windows/PowerShell-first setup and commands.
- BioNLI, NLI4CT, ChemProt, DDI2013 and BioRED adapters.
- MedNLI manual adapter.
- Resumable public-dataset preparation.
- BioRED `bioc` dependency fix.
- Unified NLI and relation-classification schemas.
- OpenJev and Qwen baseline wrappers.
- Supervised biomedical encoder training pipeline.
- Calibration and classification metrics.
- Multi-run suites and aggregation.
- Disk-usage reporter.
- `# %%` Python walkthrough.
- Jupyter walkthrough.
- Unit tests and CI.

## Sprint boundary

No PubMed continual pretraining and no BioJev fine-tuning are part of Sprint 1. The purpose of this release is to freeze a trustworthy benchmark layer first.
